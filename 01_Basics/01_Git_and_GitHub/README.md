# Что такое GitHub и зачем он нужен?

Представь, что я прислал тебе инструкцию по почте, а через неделю исправил в ней ошибку. Если отправить ещё один файл, придётся искать в письмах последнюю версию. С GitHub проще: я исправляю текст, а ты открываешь ту же ссылку и видишь обновлённую инструкцию.

**Git** запоминает изменения в файлах. С его помощью можно посмотреть, какие слова я исправил, и вернуть прежний текст. **GitHub** — сайт, на котором можно хранить эти файлы и делиться ими. Наше собрание инструкций на этом сайте называется **репозиторием**.
