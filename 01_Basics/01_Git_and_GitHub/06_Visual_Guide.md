# GitHub в картинках

Это официальные иллюстрации из документации GitHub, а не снимки нашего закрытого проекта. Оранжевые рамки уже нанесены авторами документации. Вид кнопок может немного отличаться.

## 1. Создание проекта

В меню + выберите New repository — новый проект.

![Создание проекта](https://raw.githubusercontent.com/github/docs/main/assets/images/help/repository/repo-create-global-nav-update.png)

[Открыть изображение крупнее](https://raw.githubusercontent.com/github/docs/main/assets/images/help/repository/repo-create-global-nav-update.png)

## 2. Владелец проекта

Owner — аккаунт, которому принадлежит проект.

![Владелец проекта](https://raw.githubusercontent.com/github/docs/main/assets/images/help/repository/create-repository-owner.png)

[Открыть изображение крупнее](https://raw.githubusercontent.com/github/docs/main/assets/images/help/repository/create-repository-owner.png)

## 3. Название

Repository name — название проекта.

![Название](https://raw.githubusercontent.com/github/docs/main/assets/images/help/repository/create-repository-name.png)

[Открыть изображение крупнее](https://raw.githubusercontent.com/github/docs/main/assets/images/help/repository/create-repository-name.png)

## 4. Выбор ветки

Кнопка main показывает текущую ветку.

![Выбор ветки](https://raw.githubusercontent.com/github/docs/main/assets/images/help/branches/branch-selection-dropdown-global-nav-update.png)

[Открыть изображение крупнее](https://raw.githubusercontent.com/github/docs/main/assets/images/help/branches/branch-selection-dropdown-global-nav-update.png)

## 5. Новая ветка

Введите имя отдельной ветки для изменений.

![Новая ветка](https://raw.githubusercontent.com/github/docs/main/assets/images/help/repository/new-branch.png)

[Открыть изображение крупнее](https://raw.githubusercontent.com/github/docs/main/assets/images/help/repository/new-branch.png)

## 6. Добавление файла

Add file — добавить файл.

![Добавление файла](https://raw.githubusercontent.com/github/docs/main/assets/images/help/repository/add-file-buttons.png)

[Открыть изображение крупнее](https://raw.githubusercontent.com/github/docs/main/assets/images/help/repository/add-file-buttons.png)

## 7. Предварительный просмотр

Preview — посмотреть, как будет выглядеть текст.

![Предварительный просмотр](https://raw.githubusercontent.com/github/docs/main/assets/images/help/repository/new-file-preview.png)

[Открыть изображение крупнее](https://raw.githubusercontent.com/github/docs/main/assets/images/help/repository/new-file-preview.png)

## 8. Сохранение

Выберите, в какой ветке сохранить изменения.

![Сохранение](https://raw.githubusercontent.com/github/docs/main/assets/images/help/repository/choose-commit-branch.png)

[Открыть изображение крупнее](https://raw.githubusercontent.com/github/docs/main/assets/images/help/repository/choose-commit-branch.png)

## 9. Сравнение версий

Красные строки удалены, зелёные добавлены.

![Сравнение версий](https://raw.githubusercontent.com/github/docs/main/assets/images/help/repository/diffs.png)

[Открыть изображение крупнее](https://raw.githubusercontent.com/github/docs/main/assets/images/help/repository/diffs.png)

## 10. Объединение

После проверки можно объединить изменения, если есть необходимые права.

![Объединение](https://raw.githubusercontent.com/github/docs/main/assets/images/help/pull_requests/merge-pull-request-options.png)

[Открыть изображение крупнее](https://raw.githubusercontent.com/github/docs/main/assets/images/help/pull_requests/merge-pull-request-options.png)
