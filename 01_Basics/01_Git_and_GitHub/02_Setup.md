# 02. Как начать пользоваться GitHub

## Вариант 1. Через сайт (рекомендуется для первого знакомства)

Устанавливать программы не нужно.

1. Войдите на [GitHub](https://github.com/).
2. Откройте [форму нового репозитория](https://github.com/new).
3. Введите название git-training.
4. Выберите Private (закрытый проект).
5. Включите Add README (создать файл с описанием).
6. Нажмите Create repository.

На экране появится проект с первым файлом. Подробнее о создании файлов, веток и проверке изменений — в [главе о рабочем процессе](03_Workflow.md).

## Вариант 2. На компьютере (дополнительно)

Git нужен для работы с файлами на своём компьютере. Его можно скачать с [официального сайта](https://git-scm.com/downloads). На Windows доступен Git for Windows, на macOS Git может входить в инструменты разработчика Apple.

Терминал — окно, где можно вводить команды. Откройте его и введите:

~~~bash
git --version
~~~

Если появилось название Git и номер версии, программа установлена.

Чтобы подписывать свои изменения, настройте имя и адрес:

~~~bash
git config --global user.name "Your Name"
git config --global user.email "YOUR_EMAIL"
~~~

Замените значения в кавычках своими данными. Эти команды не выполняют вход в GitHub. Для защиты личного адреса можно использовать адрес noreply из настроек GitHub.

## Как скачать проект на компьютер

На странице своего репозитория нажмите Code и скопируйте HTTPS-адрес. В терминале введите git clone, затем пробел и скопированный адрес. Для закрытого проекта потребуется авторизация. Не используйте пароль аккаунта как пароль Git по HTTPS.

Если нужен отдельный локальный проект для тренировки без GitHub, создайте новую папку git-local-training, откройте её в терминале и выполните git init -b main. Создайте README.md в редакторе, затем выполните git add README.md и git commit -m "First version". Это необязательное упражнение.

## Какие файлы не стоит загружать

Файл .gitignore содержит список файлов и папок, которые Git должен игнорировать. Например, .env может содержать секретные настройки. Уже сохранённый секрет нужно отозвать или заменить: добавление .gitignore не убирает его из истории.
