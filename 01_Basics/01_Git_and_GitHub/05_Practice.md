# 05. Практические задания

Работу выполняйте в отдельном локальном учебном репозитории, не в рабочем корпоративном проекте.

## Задание 1. История отчёта

Создайте git-training по инструкции установки. Создайте report.md с текстом:

```text
# Отчёт по продажам
Москва: 120000
Казань: 80000
Итого: 200000
```

Добавьте и закоммитьте файл. Затем добавьте строку Сочи: 60000 и измените итог на 260000. До второго коммита выполните git diff и объясните, что он показывает. Сохраните второй коммит.

Ожидаемый результат: история содержит две версии отчёта, итог второй версии равен 260000.

## Задание 2. Ветки

```bash
git switch -c feature/region-filter
```

Добавьте в report.md описание фильтра регионов, выполните git add report.md и git commit. Переключитесь на main и сравните содержимое файла. Объедините ветку:

```bash
git merge feature/region-filter
git log --oneline --graph --all
```

Ожидаемый результат: описание фильтра появилось в основной ветке.

## Задание 3. Конфликт

После предыдущих заданий создайте отдельный файл formula.txt со строкой total = revenue, добавьте и закоммитьте его на main. Создайте ветку feature/net-sales и замените строку на total = revenue - refunds. Сделайте коммит. Вернитесь на main и замените исходную строку на total = revenue - discounts, затем закоммитьте.

Выполните git merge feature/net-sales. Ожидается конфликт. Учебное требование: учитывать оба вычета. Запишите total = revenue - refunds - discounts, уберите маркеры конфликта и завершите слияние через git add formula.txt и git commit. Для выручки 100, возвратов 10 и скидок 5 ожидаемый итог — 85.

## Задание 4. GitHub

В отдельном учебном репозитории отправьте ветку на GitHub и создайте pull request. В описании укажите цель, список изменений и результаты проверок. Сделайте скриншот вкладки Files changed без личных данных.
