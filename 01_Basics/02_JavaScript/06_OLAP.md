# 06. JavaScript в отчётах и OLAP

OLAP помогает рассматривать одни и те же данные с разных сторон. Например, продажи по городам и месяцам.

| Город | Январь | Февраль | Итого |
| --- | ---: | ---: | ---: |
| Москва | 70000 | 50000 | 120000 |
| Казань | 30000 | 50000 | 80000 |
| Сочи | 20000 | 40000 | 60000 |
| Все города | 120000 | 140000 | 260000 |

Выбираем Москву — остаётся 120000. Выбираем январь — сумма всех городов за месяц равна 120000. JavaScript помогает показывать выбранные данные и обновлять итог.

## Слова, которые встречаются в аналитике

| Слово | Что означает |
| --- | --- |
| Измерение | Признак, например город или месяц |
| Показатель | Число, например сумма продаж |
| Фильтр | Отбор нужных строк |
| Агрегация | Объединение чисел, например сложение |
| Pivot | Перестановка признаков по строкам и столбцам |

## Кто выполняет работу?

Frontend — то, что видно на экране. Backend — программа на сервере. API — правила обмена данными между ними.

~~~mermaid
flowchart LR
 A[Выбор города] --> B[Сервер получает запрос]
 B --> C[Сервер считает продажи]
 C --> D[Браузер показывает итог]
~~~

Если данных миллионы строк, сервер обычно рассчитывает итог, а браузер показывает только нужный результат. Сервер также проверяет, имеет ли пользователь право видеть эти данные.

Большую таблицу можно загружать частями. Виртуализация означает, что браузер рисует только видимую часть таблицы, а не все строки сразу.

## Что проверить?

Итог должен соответствовать выбранным фильтрам. Если строк нет — показать ноль или другое заранее согласованное значение. Среднее от нескольких средних не всегда даёт правильное общее среднее, потому что в группах может быть разное число записей.

[Учебный отчёт](report.html) показывает простую фильтрацию, а не полноценную OLAP-систему. Устройство конкретного проекта нужно уточнять отдельно.
