# 02. Где попробовать JavaScript

## Самый простой способ: готовый отчёт

Откройте [report.html](report.html) на GitHub и скачайте исходный файл через Download raw file. Затем откройте скачанный файл двойным щелчком. Браузер покажет таблицу. Можно менять фильтры без установки программ.

На GitHub обычно виден сам код, а не работающая страница.

## Попробовать одну команду

На собственной учебной странице откройте меню браузера → инструменты разработчика → Console. Введите:

~~~js
console.log(2 + 3);
~~~

Нажмите Enter. Результат — 5. Console (консоль) — окно для коротких команд и сообщений программы. Не вводите незнакомый код на сайтах, где вы вошли в аккаунт.

## Дополнительно: Node.js

Для запуска программ вне браузера установите поддерживаемую LTS-версию с [nodejs.org](https://nodejs.org/). LTS — версия с длительной поддержкой.

В терминале введите node --version. Если появился номер версии, всё готово. npm — программа для установки дополнительных библиотек; в наших примерах они не нужны.

Скачайте репозиторий через GitHub или git clone. Откройте папку курса 02_JavaScript в VS Code (редакторе кода). В его терминале выполните по очереди:

~~~bash
node advanced/sales.mjs
node --test advanced/sales.test.mjs
~~~

Первая команда запускает расчёт, вторая — автоматические проверки. Для учебного сервера отдельно выполните node advanced/server.mjs и откройте http://127.0.0.1:3000 в браузере. Остановка сервера — Ctrl+C.

Если команда node не найдена, проверьте установку. Если файл не найден, убедитесь, что открыта нужная папка.
