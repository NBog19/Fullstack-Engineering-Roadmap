# 02. Настройка окружения

## Как попробовать без установки программ

Для первого знакомства достаточно браузера. Откройте пустую вкладку или собственную учебную страницу, затем инструменты разработчика через меню браузера. Console — окно для выполнения команд JavaScript. Введите console.log(2 + 3) и нажмите Enter. Результат — 5.

Для более серьёзной работы нужен Node.js (программа для запуска JavaScript вне браузера) и редактор VS Code. LTS означает версию с длительной поддержкой.

Если хочется только посмотреть учебный отчёт, скачайте [report.html](examples/report.html) из GitHub и откройте сохранённый файл браузером. Node.js для этого не нужен. На сайте GitHub сам исходный HTML-файл обычно отображается как код.

Ниже — инструкция для запуска программ и тестов на компьютере.

## Браузер

Откройте инструменты разработчика через меню браузера и выберите Console. Выполните собственный учебный код:

```js
console.log("JavaScript работает");
console.log([10, 20, 30].reduce((a, b) => a + b, 0));
```

Ожидаемый результат: сообщение и число 60. Не вставляйте незнакомый код из интернета в консоль страниц, где вы авторизованы.

## Node.js

Установите поддерживаемую LTS-версию с [официального сайта](https://nodejs.org/). Откройте терминал:

```bash
node --version
npm --version
```

npm — менеджер пакетов. Он нужен для установки зависимостей и запуска сценариев проекта. Для наших примеров сторонние пакеты не требуются.

## VS Code и запуск примеров

Клонируйте репозиторий (для приватного репозитория потребуется доступ), откройте его в VS Code и в терминале из корня выполните:

```bash
cd 01_Basics/02_JavaScript
node examples/sales.mjs
node --test examples/sales.test.mjs
node examples/server.mjs
```

После запуска сервера откройте http://127.0.0.1:3000 в браузере. Остановить сервер можно через Ctrl+C. Если порт занят, освободите его или измените номер в учебном сервере.

Расширение .mjs явно обозначает ECMAScript-модуль. Файл report.html также можно открыть непосредственно в браузере: он работает с локальными демонстрационными данными.

## Диагностика

| Проблема | Проверка |
| --- | --- |
| node: command not found | Установка Node.js и PATH |
| Cannot find module | Текущий каталог и имя файла |
| SyntaxError | Строка ошибки, скобки, кавычки |
| EADDRINUSE | Порт уже занят |

Скриншоты своего окружения следует сделать после выполнения команд.
