# 07. Первые упражнения по JavaScript

Не нужно сразу уметь писать программы. Начнём с готовой таблицы, затем попробуем несколько коротких команд. Все данные в примерах вымышленные.

## 1. Посмотреть готовую программу (без кода)

1. Откройте [report.html](report.html) на GitHub.
2. Скачайте файл через кнопку скачивания исходного файла (Download raw file).
3. Откройте скачанный файл двойным щелчком. Он откроется в браузере.
4. Выберите Москву и нажмите «Применить».

Вы увидите одну строку и итог 120 000. Нажмите «Сбросить» — снова появятся три города и итог 260 000. Так JavaScript управляет таблицей.

## 2. Первая команда

Откройте учебную страницу в браузере. В меню браузера найдите инструменты разработчика и вкладку Console (консоль). Введите команду и нажмите Enter:

~~~js
console.log("Привет!");
~~~

console.log выводит сообщение в консоль. Результат: Привет!

В каждом следующем примере можно обновить учебную страницу, чтобы начать с чистой консоли. Не вводите незнакомый код на страницах, где вы авторизованы.

## 3. Посчитать стоимость покупки

~~~js
const price = 100;
const count = 3;
console.log(price * count);
~~~

price — цена, count — количество, знак * означает умножение. Получится 300. Попробуйте поменять количество на 5: результат станет 500.

## 4. Посчитать сумму продаж

~~~js
const amounts = [120000, 80000, 60000];
let total = 0;

for (const amount of amounts) {
  total = total + amount;
}

console.log(total);
~~~

Первая строка — список трёх чисел. total — итог, вначале он равен нулю. Цикл for по очереди прибавляет каждое число. Результат: 260000.

## 5. Оставить только нужные продажи

~~~js
const sales = [120000, 80000, 60000];
const result = sales.filter(value => value >= 80000);
console.log(result);
~~~

filter означает «отобрать». Для каждого числа проверяется условие: оно не меньше 80000? Останутся 120000 и 80000. Это тот же принцип, что у фильтра в таблице.

## 6. Сделать кнопку

Сохраните следующий текст в обычном текстовом файле с именем button.html (не button.html.txt). Откройте его в браузере.

~~~html
<button onclick="alert('Отчёт готов')">Показать сообщение</button>
~~~

button создаёт кнопку. onclick задаёт действие при нажатии. alert показывает сообщение. В больших программах события обычно подключают отдельно, как показано в [главе DOM](04_DOM.md).

## 7. Дополнительно: задания для разработчика

Эта часть не обязательна для первого знакомства. Сначала установите Node.js по [инструкции](02_Setup.md).

- Запустите `node advanced/sales.mjs` из папки курса. Программа выводит итог всех продаж и итог после фильтрации.
- Запустите `node --test advanced/sales.test.mjs`. Тесты проверяют ожидаемые результаты. После знакомства с тестами попробуйте добавить проверку Казани с порогом 90000: строк не должно быть.
- Запустите `node advanced/server.mjs`. Откройте [учебный адрес](http://127.0.0.1:3000/api/report?min=80000). Сервер должен вернуть две строки и итог 200000. При min=abc ожидается ошибка 400. Остановка — Ctrl+C.
- Если знакомы с Python, попробуйте повторить фильтрацию и суммирование на нём.

## Самопроверка

Что делает кнопка? Почему после фильтрации меняется итог? Чем отличается вывод в консоль от отображения на странице?

Фактические результаты упражнений записываются после выполнения. Приведённые выше результаты — ожидаемые, а не отчёт о проведённой проверке.
