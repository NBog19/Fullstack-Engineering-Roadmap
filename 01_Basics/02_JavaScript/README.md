# Что делает JavaScript на сайте?

Представь страницу с вопросом и кнопкой «Показать ответ». Ты нажимаешь кнопку, и под вопросом появляется пояснение. Такую реакцию страницы можно описать на языке **JavaScript**.

Разработчик пишет для кнопки инструкцию: «Когда читатель нажмёт сюда, покажи текст ответа». Эту инструкцию выполняет браузер — программа, в которой открыта страница.
