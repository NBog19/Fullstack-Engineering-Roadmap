# Дополнительные примеры для разработчика

Эта папка не нужна для первого знакомства с JavaScript. Если хочется просто увидеть работу программы, откройте [готовый отчёт](../report.html).

Здесь сохранены три файла для дальнейшего обучения:

- sales.mjs — обработка и фильтрация продаж.
- sales.test.mjs — автоматические проверки расчётов.
- server.mjs — учебный сервер, который возвращает данные отчёта.

После установки Node.js откройте терминал в папке 02_JavaScript. Команды:

~~~bash
node advanced/sales.mjs
node --test advanced/sales.test.mjs
node advanced/server.mjs
~~~

Последняя команда запускает сервер. Откройте http://127.0.0.1:3000. Остановка — Ctrl+C.
