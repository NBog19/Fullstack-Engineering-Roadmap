# 03. Первые команды JavaScript

Синтаксис — правила записи команд. Будем разбирать по одной идее. Примеры можно выполнять в консоли учебной страницы из [главы 02](02_Setup.md). Между независимыми примерами можно обновить страницу.

## 1. Переменные

~~~js
const price = 100;
let count = 3;
console.log(price * count);
~~~

price — имя цены, count — количество. const означает, что переменной нельзя присвоить другое значение. let позволяет это сделать. console.log выводит результат. Здесь получится 300.

Текст записывают в кавычках, числа — без кавычек. true и false означают «да» и «нет».

## 2. Условия

~~~js
const amount = 120000;
if (amount >= 100000) {
  console.log("План выполнен");
}
~~~

if означает «если». Знак >= означает «больше или равно». Команда внутри фигурных скобок выполняется, когда условие верно.

## 3. Функции

~~~js
function calculate(price, count) {
  return price * count;
}
console.log(calculate(100, 3));
~~~

Функция — набор команд с именем. В неё передают цену и количество. return возвращает результат. Здесь результат 300.

## 4. Списки и циклы

~~~js
const amounts = [120000, 80000, 60000];
let total = 0;
for (const amount of amounts) {
  total = total + amount;
}
console.log(total);
~~~

Квадратные скобки создают список (массив). Цикл for по очереди берёт каждое число и прибавляет его к итогу. Получится 260000.

## 5. Объекты

~~~js
const row = { region: "Москва", amount: 120000 };
console.log(row.amount);
~~~

Объект хранит несколько связанных значений. Здесь одна строка отчёта содержит город и сумму. Через точку можно обратиться к нужному значению.

## 6. Фильтрация

~~~js
const sales = [120000, 80000, 60000];
console.log(sales.filter(value => value >= 80000));
~~~

filter перебирает числа и оставляет подходящие. Стрелка => отделяет входное значение от условия. Результат — 120000 и 80000.

## Дополнительно для разработчика

map преобразует каждый элемент списка, reduce собирает элементы в один итог. Например, [10,20,30].reduce((sum,x) => sum+x,0) даёт 60. Ноль — начальный итог.

=== сравнивает значения без автоматического преобразования типов. Число 5 и строка "5" при таком сравнении различны.

Модули позволяют разделять код по файлам: export делает функцию доступной другим файлам, import подключает её. Это показано в [примерах](advanced/sales.mjs).

Если уже знакомы с Python: список — это массив, def соответствует function, None примерно соответствует null, а len(items) — items.length.

Для денежных расчётов в реальных проектах важно учитывать точность чисел. В наших примерах суммы целые.
