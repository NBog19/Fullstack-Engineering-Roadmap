# Журнал работы

Здесь я фиксирую фактически выполненную работу и затраченное на неё время. Подготовка материалов с помощью ИИ, самостоятельное изучение, проверка примеров и редактирование отмечаются отдельно. Время заполняется по факту, с учётом договорённостей об оплате.

| Дата | Задача | Что сделано лично | Использованные инструменты | Фактическое время | Результат / ссылка |
| --- | --- | --- | --- | --- | --- | --- |
| | | | | | |

## Как вести журнал

1. Записать время начала и окончания работы, исключить перерывы.
2. Описать выполненные действия: чтение документации, проверка кода, подготовка схем, редактирование.
3. Приложить ссылку на коммит, файл или результат проверки.
4. Не отмечать задания как выполненные до их реального выполнения.
