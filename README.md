# Fullstack-Engineering-Roadmap

Я изучаю Full-stack-разработку — создание веб-приложений от видимой части сайта до серверной обработки данных. В этом репозитории собраны учебные материалы, примеры и задания, которые помогают разобраться в технологиях корпоративных аналитических приложений.

OLAP — анализ данных по нескольким признакам: например, продажи по товарам, городам и месяцам.

## С чего начать

- [GitHub в картинках](01_Basics/01_Git_and_GitHub/06_Visual_Guide.md) — куда нажимать.
- [Словарь терминов](GLOSSARY.md) — объяснения без программирования.
- [Карта технологий](TECHNOLOGY_MAP.md) — как устроено приложение.

- [Git и GitHub](01_Basics/01_Git_and_GitHub/README.md) — как разработчики сохраняют историю проекта и работают вместе.
- [JavaScript](01_Basics/02_JavaScript/README.md) — как работают кнопки, фильтры, таблицы и запросы к серверу.
- [Журнал работы](WORK_LOG.md) — история подготовки материалов.

Для первого знакомства достаточно читать пояснения и примеры. Команды и практические задания предназначены для самостоятельной работы на компьютере.

## Дальнейшие направления

1. Основы программирования.
2. Frontend — видимая часть приложения.
3. Backend — серверная обработка запросов.
4. Взаимодействие браузера и сервера.
5. Работа с данными и OLAP.
6. Серверы и запуск приложений.
7. Дополнительные технологии.

Цель — понимать назначение технологий, учиться применять их и проверять результаты на практике.
