# Как связаны технологии

Представим, что руководитель хочет посмотреть продажи в Москве.

~~~mermaid
flowchart TD
 U[Руководитель выбирает город] --> F[Frontend: таблица и кнопки]
 F -->|Запрос через API| B[Backend: сервер]
 B --> D[Хранилище продаж]
 D --> B
 B -->|Ответ с итогом| F
 F --> R[Руководитель видит отчёт]
 G[Git и GitHub: история кода] -.-> F
 G -.-> B
~~~

| Технология | Зачем нужна |
| --- | --- |
| HTML | Создать таблицу |
| CSS | Сделать её удобной для чтения |
| JavaScript | Реагировать на выбор города |
| TypeScript | Помогать находить ошибки типов при разработке |
| Vue | Удобнее создавать интерфейсы |
| Node.js | Один из способов написать сервер на JavaScript |
| OLAP | Анализировать данные по разным признакам |
| Git и GitHub | Хранить историю разработки |

Это пример возможного устройства приложения, а не подтверждённая архитектура конкретного проекта. TypeScript, Vue и серверные технологии ещё предстоит изучить.
