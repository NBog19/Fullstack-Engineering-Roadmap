# Словарь простыми словами

| Слово | Значение | Пример |
| --- | --- | --- |
| Git | Программа для хранения истории изменений | Посмотреть вчерашнюю версию отчёта |
| GitHub | Сайт для хранения проектов и совместной работы | Открыть инструкцию по ссылке |
| Repository | Проект с файлами и историей | Папка учебных инструкций |
| README | Главная инструкция проекта | Оглавление |
| Commit | Сохранённая версия с описанием | Добавили новый город |
| Branch | Отдельное направление работы | Черновик нового фильтра |
| Pull Request | Предложение объединить изменения | Попросить коллегу проверить фильтр |
| Merge | Объединение изменений | Добавить проверенный фильтр |
| Conflict | Git не может сам совместить правки | Два человека поменяли одну формулу |
| Frontend | Часть программы, видимая пользователю | Таблица, кнопка |
| Backend | Серверная часть программы | Расчёт итогов |
| API | Правила общения программ | Запросить продажи за месяц |
| HTML | Структура страницы | Кнопка |
| CSS | Оформление страницы | Цвет кнопки |
| JavaScript | Язык программирования | Реакция на нажатие |
| Node.js | Среда запуска JavaScript вне браузера | Учебный сервер |
| JSON | Текстовый формат обмена данными | {"total":200000} |
| OLAP | Анализ данных по разным признакам | Продажи по городам и месяцам |
| Баг | Ошибка в программе | Неправильный итог |
| Тест | Проверка работы программы | Сравнить итог с ожидаемым |
| Библиотека | Готовый набор функций | Инструменты для таблиц |
| Деплой | Размещение программы в рабочей среде | Сделать обновление доступным пользователям |
